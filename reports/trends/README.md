# Harness trends, day by day

One file per day, named `<YYYY-MM-DD>.md`, written by the daily run of
[`skills/harness-trends/`](../../skills/harness-trends/). Each holds at most three trends from the day before,
one recommended change to the harness, the pulse question that asks the team about
it, and whether it was proposed. The files are gitignored, so they stay here on the
machine that wrote them; only this README is tracked. The sprint run of the same
skill lists them in its report, with how the team voted.

They hold counts and the names of harness parts, never a prompt, a file path, a
command or code.
